2. Usage Assessment — Score Each Tool (1-5)

For each tool listed above, score it on each of the four criteria below. Be honest.

Scoring guide:

A. How often is it used?
  • 5 = Daily by multiple people
  • 3 = Weekly or occasional use
  • 1 = Rarely or never since initial signup
B. What work does it do?
  • 5 = Core work (drafting content, coding, analysis)
  • 3 = Helpful but not essential
  • 1 = Novelty / experimentation
C. Could a different tool do this?
  • 5 = Yes, multiple alternatives available
  • 3 = Maybe, but this one is convenient
  • 1 = No, it's specialized for our needs
D. Does it handle sensitive data?
  • 5 = Yes — customer data, IP, internal docs
  • 3 = Sometimes
  • 1 = No, only public/generic queries

3. Red Flags

Check every item that applies to your AI stack.

Tools nobody uses but keeps paying for
Multiple tools doing the same thing (e.g., two writing assistants)
Enterprise plan for a small team that doesn't need it

No idea what the monthly total actually is

4. Your Score

Quick rules of thumb:

  • Any tool with an average score below 3 is probably not worth keeping.
  • 2 or more red flags = you're leaving money on the table.
  • High "sensitive data" scores on multiple tools = consider local alternatives.
  • Multiple tools with overlapping use cases = consolidate or cancel duplicates.
