Frequently asked questions

Do I need to schedule a call?

No. We do everything asynchronously by default. Send your brief via email, we review it, and send you a proposal. If you would prefer to talk, mention it. We can accommodate that.

Do I need technical knowledge?

No. We handle the technical setup and explain everything in plain language. You just need to tell us about your business and what is painful.

Where does the AI run?

On your infrastructure. If you have local hardware (a server, a powerful workstation), we deploy there. If not, we can deploy on a private cloud instance (Hetzner, DigitalOcean, AWS) that you control. Either way, your data stays yours and there are no per-query API fees.

What kind of businesses do you work with?

Professional services, healthcare practices, marketing agencies, legal firms, e-commerce teams, and any small-to-mid-size business with repetitive work and data they should not be sharing publicly.

Why local AI instead of just using ChatGPT or Claude?

Three reasons: (1) Your data never leaves your network. Critical if you handle client information, medical records, legal documents, or financial data. (2) No ongoing API costs. You pay once for setup, then nothing per query. (3) You own the system. No vendor lock-in, no policy changes breaking your workflow overnight.

How long does a project take?

Workflow automations: 5–10 business days depending on complexity. Local AI deployments: 1–2 weeks. Spending audits: 48 business hours. We give you a clear timeline before we start.

What if it does not work out?

Every engagement has defined scope and deliverables upfront. You will not be billed for work that does not meet what we agreed on. If the system does not do what we committed, we fix it at no extra cost. Every project includes a walkthrough and documentation. If your team cannot use what we built within two weeks, we will help until they can.

Do you offer ongoing support?

Yes. Optional monthly retainers ($1,000–2,000/month) for maintenance, updates, and new projects. But every initial engagement is fixed-price. No ongoing commitment is required.

Open source tools

We build tools that make consulting work repeatable. These are open source for transparency and so you can audit our approach before we touch your account.

aws-health-audit

Read-only AWS account audit. Finds cost waste, exposed resources, and CIS gaps. Produces a report a person can read and a JSON a pipeline can parse.

Use before a bill review, a security questionnaire, or a handover.

HarderAWS

Opinionated AWS security hardening as Terraform modules. CIS-compliant CloudTrail, IAM guardrails, logging, VPC controls, GuardDuty, Config.

Use to harden a client account in one apply.

tf-cost-preview

Estimates the monthly run rate of a Terraform plan from its JSON output. Offline, no API calls, no network. Tells you "what will this plan cost" before apply.

Use in a client review when the question is cost, not invoice.

secure-ci-templates

Opinionated GitHub Actions workflows for freelance delivery. Copy-paste CI/CD for Python, Node, Go, and Terraform with OIDC, CodeQL, and Trivy.

Use to ship client code with security scanning built in.

All tools are MIT-licensed. If you find a bug or have a suggestion, open an issue on GitHub. If you want us to run these against your account, email us.
